Smart App Launcher opens every app, document, folder, and browser tab a task
needs — in one click, or automatically. This repository hosts the public Windows
installer.

## What it does

- **One-click launching** — open a whole workspace of apps, files, folders, and
  browser tabs in the order and on the monitors you chose.
- **Automatic triggers** — mark one app as the trigger and the rest of the
  workspace follows; or launch on a schedule.
- **Windows & monitors** — capture a layout and rebuild each window's position,
  size, and stacking order on every launch.
- **Routine learning** — learns the apps you open together and suggests a
  ready-made workspace (opt-in, all analysis runs locally).

See the full feature list on the [website](https://smartapplauncher.netlify.app/).
